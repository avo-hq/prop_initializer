prop_initializer

Properties for any Ruby class

One prop line per property. The initializer, readers, writers and to_h are generated when the class loads, so nothing runs at call time but the assignments. No types to declare.

Built on Literal. A fork of Joel Drapper’s properties system with the type checks taken out. Every component in the Avo admin framework declares its props this way.
You writebutton_component.rb
class ButtonComponent
  extend PropInitializer::Properties

  prop :record, kind: :positional
  prop :label, reader: :public
  prop :size, default: :md
  prop :items, default: -> { [] }
  prop :icon do |value|
    value&.to_sym
  end
end

def initialize(record = nil, label: nil, size: :md,
               items: Null, icon: nil)
  @record = record
  @label  = label
  @size   = size
  @items  = Null == items ? [] : items   # proc, per instance
  @icon   = instance_exec(icon, &coercion)
  after_initialize if respond_to?(:after_initialize)
end

attr_reader :label
def to_h = { record: @record, label: @label, size: @size,
             items: @items, icon: @icon }

Every argument kind

Keyword by default. Also :positional, :*, :** and :&, in Ruby’s order.

Defaults

A frozen value or a proc called once per instance. An explicit nil stays nil.

Coercion blocks

Run on the new instance, after the default, with earlier props already assigned.

Readers, writers, predicates

None unless asked. reader:, writer: and predicate: take a visibility.

after_initialize

Define it and it runs once every prop is assigned. to_h returns them all.
