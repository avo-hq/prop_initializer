Ruby gem · by Avo

prop
initializerproperties for any Ruby class

Declare props, get an initializer. Defaults, coercion, readers and writers from one line per property. No types to declare.

  • Built on Literal. Joel Drapper’s properties system, with the type checks taken out.
  • Fast. The initializer is generated once, at class load. Props with no default cost one assignment.
  • Powers Avo. Every component in the Avo admin framework declares its props this way.

button_component.rb
class ButtonComponent
  extend PropInitializer::Properties

  prop :label, reader: :public
  prop :size, default: :md
  prop :items, default: -> { [] }
  prop :icon do |value|
    value&.to_sym
  end
  prop :record, kind: :positional
  prop :options, kind: :**

  def after_initialize
    @label ||= "Save"
  end
end

ButtonComponent.new(post, icon: "check")

  @icon=:check @options={}>

One extend, one method

prop declares a property. The initializer, readers and writers are generated right there, at class load.

Readers, writers, predicates

Off by default. Ask for reader:, writer: or predicate: with the visibility you want.

Defaults

A frozen value, or a proc called once per instance. Pass nil explicitly and it stays nil.

Coercion blocks

Run on the new instance, after the default, with every earlier prop already assigned.

Every kind of argument

Keyword by default. Also :positional, :*, :** and :&, in Ruby’s own order.

after_initialize

Define it and it runs once every prop is assigned. Values land in ivars; to_h returns them all.
